# QA Bot

A Question Answering chatbot using BERT and semantic search.

## Tasks

- **0-qa.py**: Single-document QA using BERT (tensorflow-hub + transformers)
- **1-loop.py**: Simple Q&A input loop
- **2-qa.py**: Loop-based QA over a single reference document
- **3-semantic_search.py**: Semantic search over a corpus using Universal Sentence Encoder
- **4-qa.py**: Multi-document QA combining semantic search with BERT
